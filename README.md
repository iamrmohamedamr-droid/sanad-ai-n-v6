# SANAD AI V4 — سند

منصة عربية RTL للإتاحة الرقمية، مبنية باستخدام React 18 + TypeScript + Vite، ومهيأة للنشر على Vercel.

## تحديثات V4.1

- **عين سند بالعربية فعلًا:** المزود الأساسي أصبح Google Gemini (طبقة مجانية) ويجيب بالعربية مباشرة. إذا استُخدم Moondream (يجيب بالإنجليزية غالبًا) تُترجم نتيجته تلقائيًا للعربية، وسؤالك العربي يُترجم للإنجليزية قبل إرساله له.
- **اختيار اللهجة:** مصري بسيط أو فصحى مبسطة (يؤثر في النص والقراءة الصوتية).
- **APIs مجانية:** Gemini للرؤية والنص، وويكيبيديا العربية وDuckDuckGo Instant Answer للبحث في «اسأل سند»، وMyMemory كترجمة احتياطية بدون مفتاح.
- **سلسلة احتياط ذكية:** Gemini ← Moondream ← OpenAI (قابلة للتغيير بمتغير `VISION_ORDER`).
- **حد للطلبات:** `RATE_LIMIT_PER_MIN` (طبقة مساعدة داخل الدالة، وليست بديلًا عن حماية مزود الاستضافة).
- **إصلاحات:** إيقاف الكاميرا تلقائيًا عند مغادرة قسم عين سند، وإصلاح الفيديو الأسود عند العودة، وإصلاح تقادم إعدادات الرؤية المستمرة، وإصلاح ضياع النص عند الإملاء الصوتي المتواصل، وتنبيه صوتي إذا توقف التحليل المستمر، واختيار صوت عربي للقراءة، وإخفاء رموز الزينة عن قارئات الشاشة.

> **تنبيه خصوصية مهم:** في الطبقة المجانية من Gemini قد تُستخدم المدخلات لتحسين منتجات Google (خارج بعض المناطق مثل الاتحاد الأوروبي). عين سند ترسل صور الكاميرا (مستندات، منتجات، عملات…)، فأبلغ المستخدمين بذلك بوضوح، وفكّر في الطبقة المدفوعة قبل الإطلاق العام.

## موفر الرؤية: Moondream Cloud (اختياري)

يدعم المشروع Moondream Cloud عبر واجهة HTTP الرسمية:
- Base URL: `https://api.moondream.ai/v1/`
- المصادقة عبر ترويسة `X-Moondream-Auth`.
- النموذج الافتراضي: `moondream3.1-9B-A2B`.
- يستخدم `/caption` لوصف المشهد و`/query` للأسئلة والمهام البصرية المتخصصة.

عند وجود `MOONDREAM_API_KEY` تُستخدم Moondream للمهام البصرية. إذا فشل الطلب وكان `OPENAI_API_KEY` متوفرًا، يحاول الخادم استخدام OpenAI كبديل. قراءة OCR النصية تستخدم تعليمات مخصصة عبر موفر الرؤية.

## الإعداد المحلي

المتطلبات: Node.js 20 أو أحدث وnpm.

```bash
npm install
cp .env.example .env.local
npm run dev
```

أضف مفاتيح API الحقيقية إلى `.env.local` محليًا فقط. لا ترفع الملف إلى GitHub.

## النشر على Vercel

1. ارفع محتويات المجلد إلى مستودع GitHub.
2. اربط المستودع بمشروع Vercel.
3. Framework Preset: `Vite`.
4. Build Command: `npm run build`.
5. Output Directory: `dist`.
6. أضف المتغيرات التالية من Vercel → Settings → Environment Variables:
   - `MOONDREAM_API_KEY` — مفتاح Moondream Cloud.
   - `MOONDREAM_MODEL` — اختياري، الافتراضي `moondream3.1-9B-A2B`.
   - `OPENAI_API_KEY` — موصى به كبديل للرؤية ولخدمات النص.
   - `OPENAI_MODEL` — اختياري، الافتراضي `gpt-4.1-mini`.
7. أعد النشر بعد حفظ المتغيرات.

## الأذونات والمتصفح

- الكاميرا تعمل على HTTPS أو localhost، ويلزم منح إذن الكاميرا.
- يفضل استخدام هاتف بكاميرا خلفية ومتصفح حديث.
- الميكروفون والتعرف على الكلام يعتمدان على دعم المتصفح؛ جرّب Chrome أو Edge الحديث.
- القراءة الصوتية تعتمد على Speech Synthesis المتاح في الجهاز، وقد تختلف جودة الصوت العربي حسب الأصوات المثبتة.
- تحتاج التحليلات السحابية إلى اتصال إنترنت ومفاتيح API صالحة.

## التكلفة والخصوصية

- تُرسل الصورة إلى موفر الرؤية السحابي عند تشغيل تحليل يدوي أو عند تفعيل الرؤية المستمرة.
- الرؤية المستمرة ترسل إطارًا دوريًا؛ أوقفها عندما لا تحتاجها. وضع توفير الإنترنت يبطئ التحليل إلى مرة كل 12 ثانية.
- راجع أسعار Moondream وOpenAI وحدود الاستخدام الحالية قبل الإطلاق؛ التكلفة تتغير حسب الاستخدام والخطة.
- لا تحفظ هذه النسخة الصور أو المحادثات في قاعدة بيانات.
- لا تضع مفاتيح API في الواجهة أو في GitHub؛ يجب أن تبقى في Environment Variables على Vercel.
- أضف قبل الإطلاق العام نظام rate limiting موثوقًا على مستوى الحافة/مزود الاستضافة، ومراقبة استهلاك، وسياسة خصوصية وموافقة واضحة.

## تنبيه سلامة مهم

عين سند أداة مساعدة لفهم الصور وليست جهاز ملاحة أو نظام تجنب اصطدام معتمدًا. قد تفوتها عوائق أو تصفها بشكل خاطئ أو متأخر. لا تعتمد عليها لعبور الشوارع أو صعود السلالم أو التنقل الآمن؛ استمر في استخدام العصا البيضاء أو وسيلة الحركة/المرافق المعتادة.
